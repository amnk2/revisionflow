The most influential account of working memory is the multicomponent model proposed by Baddeley and Hitch in 1974. They suggested that working memory has a central executive, which directs attention and coordinates two slave systems. The first is the phonological loop, which stores sound and speech-based information, and which we keep active by rehearsing it silently. The second is the visuospatial sketchpad, which holds visual and spatial information, for example when you picture a route. In 2000, Baddeley added a fourth part, the episodic buffer, which links information across the other components and connects working memory to long-term memory.
