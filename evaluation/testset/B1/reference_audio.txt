In this part of the lecture we will walk through the fetch stage, which is the same for every instruction. The program counter contains the address of the instruction to be fetched. This address is copied to the memory address register. The control unit then sends a signal on the control bus to read memory at that address, and the data is placed on the data bus. The instruction is loaded into the memory data register, and at this point the program counter is incremented by one. Finally, the contents of the memory data register are copied into the current instruction register, where the opcode and the operand can be decoded. In the decode stage the control unit interprets the instruction, and in the execute stage the arithmetic logic unit carries out the operation.
